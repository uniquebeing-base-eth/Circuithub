Open service network

Circuithub

The service layer for humans and AI agents — making services discoverable, callable, verifiable, and payable.

Core flow

Discover → Select → Verify → Request → Pay → Track

API

Simple developer endpoints for service discovery, registration, verification, and requests.

  • GET /services
  • POST /services/search
  • POST /services/register
  • POST /requests

MCP

AI agents can use the same network through a small MCP-style tool surface.

  • search_services
  • get_service
  • request_service
  • get_request_status

Verification

Every service is checked for reachability, protocol behavior, capability match, and ownership proof where applicable.

Current MVP

This release focuses on the infra layer: a simple registry, verification workflow, HTTP API, and MCP discovery pattern. It keeps the frontend intentionally small and the product architecture open for real providers to plug in.
